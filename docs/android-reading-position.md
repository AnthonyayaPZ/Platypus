# Android 视频学习：继续上次阅读

版本：0.3.1（versionCode 5）。仅安卓修改，不需要服务端或数据库迁移。

## 交互

视频学习为连续滚动排版，因此记录字幕句子而不是固定页码。首次读文章不显示提示；有非起始进度时，重新进入该文章会从顶部展示一张浅绿色小卡片，标明上次字幕位置及视频时间，用户自己选择“继续”或“从头读”。选择后卡片收起。直接滚动到后面的句子也视为开始新的阅读过程，更新当前进度。

“继续”恢复到同一句及句内偏移；“从头读”只清除该篇的书签，不清理文章、草稿、词库或学习记录。回到标题操作控制项不会把旧书签改成第一页。仅在确有历史进度时显示，不增加常驻入口或宣传卡。

## 本机保存

- 独立的 `video-study-reading-position` SharedPreferences，不复用草稿或文章元数据的存储键。
- 按文章 ID 保存字幕 ID、原文序号、句内偏移（dp）、英文前160字符、字幕时间、句数和保存时间。
- 滚动停止后保存；离开阅读组件、应用暂停或进入后台时补存当前实际位置。系统在没有任何生命周期回调的情况下突然终止进程，可能只能保留最近一次已保存的位置。
- 使用 LazyListState 的首个可见内容项，避免误把顶部内边距中的上一张卡片末尾记录成阅读位置。
- 标题/控件区不覆盖旧书签；“只看已选”期间不写正常进度，退出筛选时恢复进入筛选前的位置。
- 每篇文章的阅读列表独立创建，离开时只写回对应文章，避免切换文章或后台翻译刷新时串位。内置文章及离线缓存使用相同逻辑。

## 字幕变化和恢复边界

优先按稳定字幕 ID 定位；该句英文变化时从句首开始，不沿用可能失效的句内偏移。ID 消失时依次尝试英文前缀、视频时间、按原进度比例估计的相近位置，始终限制到合法序号，估计结果在卡片标注“约”。没有可用正文时不跳转，不伪造精确位置。字幕经过大幅改写后只能近似定位。

## 验证与安装

自动化测试覆盖文章隔离、存储恢复、无效记录、字幕重排/缺失、可选加载和错误行、进入页面不抹除书签、确认后跳转、重新进入、从头读以及筛选视图保护。使用 Android Studio 的 `ReadingResumePreview` 可预览390dp小卡片。

记录在当前设备，不提供跨设备同步，不更改在线学习记录。覆盖安装相同签名的0.3.1 debug APK 即可，不能通过单独部署服务器获得此功能。

本轮通过30项安卓测试（新增10项进度/界面测试）、`lintDebug` 和 `assembleDebug`；未做实体手机测试。APK包名及签名沿用0.3.0 debug版本，安装后开始记录进度，旧版未曾记录的滚动位置不能追溯恢复。构建在原有隔离验证目录使用本机JDK完成，没有改动项目的Gradle JDK配置。本轮仅修改本地安卓代码和文档，没有推送或变更服务器。
