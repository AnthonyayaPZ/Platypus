# Android 0.4.0：卡片、词库详情与练习选项

## 卡片与详情

- 卡片背面的释义下直接显示近义词和反义词；下方继续提供完整中文辨析和适用场景。新旧词条均兼容：优先使用 `relations` 的详情，再用已有 `synonyms` / `antonyms` 补足名称，不凭空生成比较。
- 没有可靠关联词时显示一行灰色说明，不调用 LLM 凑数。
- “加入练习”位于卡片顶部计数旁，翻面前后都可操作，再点一次可取消。不会因加入队列而翻面或切换当前单词。
- 词库点击单词行打开与原页面同色系的底部详情面板，包括音标、词性、释义、例句、近反义词及笔记入口。已有发音、编辑笔记、移出词库按钮保留独立操作，不误触详情。

## 优先练习

- 队列在当前安卓设备持久保存（`review-priority`），最多200词，重复选择不会产生重复项；不与视频草稿、阅读位置或文章缓存混存。
- 下一轮按当前词库过滤队列；已加入的词即使尚未到复习日期也会入选，并排在普通到期词之前。每轮最多10词，每词仍有3题；未入选或未练完的优先词保留到下一轮。
- 已开始的会话保持原题目和已答成绩，新加入的词安排在下一轮。完成某词全部3题后才从本机优先队列移除，中途取消不消耗未完成词。最后一个词库成员关系被移除后，队列同步移除该词。
- 优先练习沿用原来的复习评分和下次复习安排，不直接修改 `next_review` 来伪造优先级。队列不跨设备同步。

## 本轮不练习听力题

- 开始前可选，选择后只出单词选义/词义选词文字题，仍保留每词3次练习，以兼容现有计分规则。
- 进行中也可关闭听力：仅把未作答听力题转换成文字题，保留题目ID、顺序、已答答案和成绩。已经答过的听力题不改写。
- 本轮关闭后不能重新打开听力，结束后下一轮重新选择，默认恢复包含听力。发音按钮始终由用户主动点击，不自动播放音频。
- 服务端将开始会话和答题串行锁定，避免题目转换与答题交错；过时题目/选项不会写入错误成绩。

## 兼容与发布

`POST /api/state` 的 `beginReview` 增加可选 `includeAudio`、`priorityWords`。`GET /api/state` 返回 `reviewFeatures` 能力标记。旧客户端/网页版不传选项时保持原三题型；新安卓若发现旧服务端不支持，不会悄悄用听力模式替代用户选择。

无需数据库结构迁移，无需重写已收藏词、笔记、文章或复习历史。安卓版本0.4.0、versionCode 6，保留0.3.1的阅读位置提示功能。安装需覆盖旧的同签名debug包，不要卸载或清除数据。
