# 阅读优先布局与学习记录

Web 与 Android 0.2.0 使用统一入口，不再显示“真实视频 / 离线演示”切换、宣传标题或演示说明卡。

- 默认直接显示文章。手机视频页不显示全局品牌栏，保留底部应用导航。
- 右下角两个 52px / 52dp 圆形入口分别展开查找、缓存区；缓存显示词数角标。
- 查找、字幕导入、视频候选、缓存编辑和批量进度都只在展开后显示。
- 顶部“学习记录”重新打开旧文章，两篇内置文章使用相同阅读器，不再切换模式。
- 服务端 `GET /api/video-study/history` 从现有字幕表读取全部记录，并幂等加入两篇内置文章，不需要新迁移。
- Web 保存历史摘要和文章快照；Android 使用历史元数据加独立原子文章文件。离线时仍可阅读本机缓存和内置文章。
- 历史同步不会覆盖本机最近打开时间；旧演示草稿只合并一次，避免升级丢词或重复添加。
- 内置文章选词同样使用真实批量收藏规则，只在手动提交后调用后台。

本轮验证：Web/服务端 19 项测试、Android 15 项测试通过；两端构建与静态检查通过。浏览器已检查 390px 阅读页、主导航、学习记录切换、刷新恢复、两个圆形入口、缓存编辑与 Escape 关闭弹层。Android 提供 `ReaderPreview` 并补充无冗余卡片/按需展开的自动交互测试；未做实体手机安装验收。

YouTube 出站网络限制不属于本次界面调整，仍沿用原有服务器状态；可使用字幕导入和内置文章。
