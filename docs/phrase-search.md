# 单词与短语检索

Web 与 Android 0.5.0 共用原来的搜索入口。输入 `look forward to`、`in terms of`、`at one's own pace` 等短语时，整个输入作为一个词典键检索、生成并缓存，不逐词拆开翻译。结果复用释义、用法摘要、双语例句、可靠的近反义表达与个人笔记。

## 输入和默认收藏

- 大小写、连续空白与弯撇号统一规范化；单词最多48字符，短语2–8个词、最多96字符。
- 仅支持英文字母、词间空格、词内连字符与撇号。逗号、句号、数字、中文等返回明确输入错误，不静默丢弃内容。
- 自动补全仍用于单个单词。短语含空格后不会被旧的单词候选覆盖；按查询键提交整个表达。
- 单词批量导入保持原有“空格/逗号/换行分隔单词”规则。本轮不增加短语批量导入，请在普通搜索框逐条检索短语。
- 系统创建独立的“短语收藏”文件夹，以稳定的 `system-phrases-local-demo` ID 识别，不靠中文名称判断。若用户已有同名普通文件夹，则新建带序号的系统文件夹，不占用、移动或重命名原收藏。
- 系统文件夹不替换原来的单词默认收藏，也不能设为单词默认或删除；可以移出其中的词条。每次新短语检索默认选中它，用户也可手动选择其他文件夹。
- 搜索结果的收藏目的地不改变卡片、背诵、词库当前分组。API `saveWord` 省略 `groupId` 时也按照单词/短语选择相应默认文件夹；显式传入时尊重用户选择并校验归属。

## 兼容和数据

沿用既有 PostgreSQL `text` 词典主键、收藏关系、笔记和复习表，无结构迁移。兼容字段名 `word` 同时容纳完整短语；`/api/state` 增加 `dictionaryFeatures` 和分组 `kind`。原来的 API、旧客户端和视频单词批量导入继续工作；旧 APK 无法输入短语，需要覆盖安装新版。

短语参与现有卡片和每词3题的复习流程，TTS 朗读完整表达，安卓优先练习队列保留完整短语。支持本轮关闭听力，已有复习安排不重置。小屏搜索标题允许自然换行，卡片短语最多5行。

LLM 使用整体短语的常见意义和语法约束，不把目标改成原形或单个词；关系可包含单词或短语，不存在可靠近反义表达时返回空数组。回包保持完整目标键并严格校验，不进行逐词兜底。

## 验证

- 服务端/前端：词条规范化、默认目的地、同名文件夹保护、幂等初始化、模型短语响应、近义短语、拒绝目标被拆写、短语优先复习以及原有回归测试。
- Android：小屏完整标题/收藏目的地、整体查询、独立选择、切回单词后的默认值、非法输入与队列重启持久化。
- 不清除用户阅读位置、字幕草稿、词库、笔记或练习成绩。
