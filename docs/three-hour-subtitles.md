# 最长3小时的手动字幕导入

Web 与 Android 0.5.1 支持手动导入时间轴终点不超过 `03:00:00.000` 的 SRT/VTT，包含3小时整。文件最大4 MiB（按UTF-8字节计），最多30000个时间轴片段、12000个原始句子、600000个英文正文字符及12000个阅读段落。保留资源保护上限，不承诺接受任意密度或损坏字幕。

YouTube自动下载保持原有配置上限，不受手动上传扩容影响。上传解析在入队前检查时长与格式，后台再独立校验；不需要视频文件、YouTube Cookie或在线视频下载。

## 长文处理

- 沿用按意群分块、每个阅读块最多24词的规则，不把长文件压成一整屏。
- 自动记录最后字幕终点为文章时长；无片尾字幕时，这是字幕覆盖时长，不代表完整视频片长。
- 后台分批翻译和逐批保存；退出页面不停止任务，重新进入可以查看进度。模型断连/配置错误时保留英文；连续两批失败后停止本次后续请求，避免长字幕反复超时和空耗请求，用户可重试未翻译部分。
- 单篇语义切分辅助最多40个不确定原句，其他使用原有无损规则，避免3小时字幕无限请求模型。
- Web每页100个阅读段落，切页不清空选词；切换文章或筛选默认从对应视图第一页开始。安卓继续使用LazyColumn和既有阅读位置保存。
- 超过600个阅读段落的文章将全文进度拉取间隔调整为10秒，减轻反复下载完整文章的负担；小文章沿用原刷新频率。
- 安卓大于10000字符的上传内容不直接渲染进编辑框，仅显示完整载入数量，仍上传全部内容，可清除重选。

接口只有字幕文档端点扩大JSON请求体限制；收藏等其他接口保持原来的750000字节限制。无需数据库结构迁移，不清除已有学习数据。

## 验证

测试覆盖3600个片段、3小时整、超过旧500KB/600句/120000正文字符/2000阅读段落的完整导入，VTT小时格式、超过3小时1毫秒拒绝、UTF-8文件字节上限、后台701句任务和只重试缺失翻译、连续失败熔断，以及安卓文件读取4MiB边界。测试使用合成字幕和模拟翻译，不对3小时字幕发起付费LLM翻译。
